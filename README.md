# CP1 - CRUD de Filmes

Projeto desenvolvido em Java utilizando JDBC e Oracle Database para gerenciamento de filmes através de um sistema CRUD no terminal.

## Sobre o projeto

O sistema permite cadastrar, consultar, atualizar e excluir filmes armazenados em um banco de dados Oracle.

O projeto foi desenvolvido com a aplicação dos padrões de projeto:

- DAO (Data Access Object)
- Factory
- Singleton

A interação com o sistema é realizada diretamente pelo terminal através de um menu de opções.

## Funcionalidades

O sistema possui as seguintes operações:

1. Cadastrar filme
2. Listar filmes
3. Buscar filme por ID
4. Atualizar filme
5. Deletar filme
0. Sair

Cada filme possui os seguintes dados:

- ID
- Título
- Diretor
- Ano de lançamento
- Gênero

## Tecnologias utilizadas

## Padrões de projeto

### Singleton

O padrão Singleton é utilizado na classe `ConnectionSingleton`.

Sua função é garantir que exista uma única conexão compartilhada com o banco de dados durante a execução da aplicação.

```text
Main
 ↓
FactoryDAO
 ↓
ConnectionSingleton
 ↓
Oracle Database
```

### DAO

O padrão DAO é utilizado para separar as operações de acesso ao banco de dados da lógica principal da aplicação.

A interface `FilmeDAO` define as operações disponíveis:

- Salvar
- Buscar por ID
- Listar todos
- Atualizar
- Deletar

A classe `FilmeDAOImpl` contém a implementação dessas operações utilizando JDBC.

### Factory

O padrão Factory é utilizado pela classe `FactoryDAO`.

Ela é responsável por criar a implementação de `FilmeDAO` e fornecer a conexão obtida pelo `ConnectionSingleton`.

Dessa forma, o `Main` não precisa criar diretamente o `FilmeDAOImpl` nem controlar a conexão com o banco.

## Banco de dados

O projeto utiliza uma tabela chamada `FILMES` no Oracle Database.

### Estrutura da tabela

| Campo | Tipo | Descrição |
|---|---|---|
| ID | NUMBER | Chave primária e identificador do filme |
| TITULO | VARCHAR2(100) | Título do filme |
| DIRETOR | VARCHAR2(100) | Diretor do filme |
| ANO_LANCAMENTO | NUMBER(4) | Ano de lançamento |
| GENERO | VARCHAR2(100) | Gênero do filme |

O campo `ID` é gerado automaticamente pelo Oracle através de uma coluna `IDENTITY`.

### Criação da tabela

```sql
CREATE TABLE FILMES (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    TITULO VARCHAR2(100) NOT NULL,
    DIRETOR VARCHAR2(100) NOT NULL,
    ANO_LANCAMENTO NUMBER(4) NOT NULL,
    GENERO VARCHAR2(100) NOT NULL
);
```

## Configuração

Para realizar a conexão com o Oracle, o projeto utiliza um arquivo local chamado `config.properties`.

Exemplo:

```properties
oracle.url=jdbc:oracle:thin:@localhost:1521:xe
oracle.user=SEU_USUARIO
oracle.password=SUA_SENHA
```

O arquivo `config.properties` não deve ser enviado para o GitHub, pois contém as credenciais utilizadas para acessar o banco de dados.

Por isso, ele está incluído no `.gitignore`.

## Como executar

### 1. Criar a tabela

Execute o comando SQL de criação da tabela `FILMES` no Oracle SQL Developer.

### 2. Configurar o banco

Crie o arquivo `config.properties` na raiz do projeto e informe as credenciais do seu banco Oracle.

### 3. Configurar o JDBC

Certifique-se de que o Oracle JDBC Driver esteja configurado no projeto.

### 4. Executar

Execute a classe `Main.java`.

O sistema apresentará um menu no terminal:

```text
==============================
       CRUD DE FILMES
==============================
1 - Cadastrar filme
2 - Listar filmes
3 - Buscar filme por ID
4 - Atualizar filme
5 - Deletar filme
0 - Sair
==============================
Escolha uma opcao:
```

A partir do menu, o usuário pode realizar todas as operações do CRUD.
